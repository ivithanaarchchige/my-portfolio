# Isuru Vithanaarchchige’s portfolio

Open `index.html` to preview the project gallery. Serve the folder over HTTP to try the browser demos. Camera-based input requires HTTPS or localhost and explicit browser permission.

## Publish for free with GitHub Pages

1. Create a public GitHub repository.
2. Upload the **contents** of this folder to the repository root, including `.nojekyll`, so that `index.html` is at the top level.
3. In **Settings → Pages**, select **Deploy from a branch**, then select your default branch and **/(root)**. Save the settings.
4. Open the published address shown in the Pages settings after deployment finishes.

The website is plain HTML, CSS, and JavaScript. It uses relative paths, so the same files work on a project site under `username.github.io/repository/`.

[GitHub Pages publishing settings](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
