FOG Game Library

A desktop storefront and game library that remembers the games attached to an account.

Remembering what a player owns

The interface separates registration and sign-in, the game store, and the personal library. A local SQLite database connects the account to its collection so the library survives a restart.

What it uses

  • Python and Tkinter
  • SQLite
  • Desktop interface and form validation
