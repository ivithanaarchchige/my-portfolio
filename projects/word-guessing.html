Word Guessing Game

A terminal word game that reveals letters while tracking incorrect guesses.

The project

A word is selected from a list and displayed with hidden letters. The program checks each guess, reveals matches, and records misses. The game ends when the word is solved or the player runs out of chances.

What it uses

  • Python
  • File input and string processing
  • Game state and validation
